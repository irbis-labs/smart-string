# Docs

This directory contains developer-facing documentation for `smart-string`.

- `api-parity.md`: `std::string::String` compatibility checklist for `SmartString`/`PascalString`.
- `std-string-methods.md`: complete bullet list of inherent `std::string::String` methods (extracted from the local Rust toolchain source).
- `std-string-methods-table.md`: `String` method list with basic properties (const / mutability / panic heuristic).
- `pascalstring-string-parity.md`: method-by-method correspondence table between `PascalString` and `std::string::String`.
- `smartstring-string-parity.md`: method-by-method correspondence table between `SmartString` and `std::string::String`.
